# Little Steps – Trusted Childcare Platform

Little Steps is a web-based childcare platform designed to help parents discover childcare services and help childcare providers present their services.

# Current Progress

- Initial React + Vite frontend setup
- Responsive homepage layout
- Navigation bar and hero section
- Childcare service cards
- Custom CSS styling
- Git and GitHub project setup

# Tech Stack

- React
- Vite
- JavaScript
- CSS

# Run Locally

1. Install [Node.js](https://nodejs.org/).
2. Open a terminal inside the `frontend` folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.

# Project Status

The project is under development. Search, authentication, booking, provider dashboards, and admin features are planned for future implementation.

# Purpose

To build a user-friendly platform that helps parents explore childcare options with a focus on convenience and safety.
